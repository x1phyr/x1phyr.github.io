# 无边

一叶孤舟，一纸空白。以马远《寒江独钓》为意，用纯 Canvas 2D 写成的一幅会呼吸的水墨小品。

- 宣纸底（米黄纸色、纤维、淡淡暗角），画面留白八成以上；
- 舟偏左，船腹、船舷各一笔，斗笠一块墨，钓竿一笔，钓丝入水处水纹一圈圈慢慢呼出；
- 疏雪极少极淡；右下一方小印；
- 久静之后，右侧会浮出一行极淡的诗句，片刻又隐去。

## 操作

| 按键 | 动作 |
|------|------|
| `W` / `↑` / `Space`（触屏：轻触） | 划一桨：舟轻轻前滑，船尾漾开一道水痕，慢慢化进纸里 |
| `A` / `←`、`D` / `→`（触屏：左右轻扫） | 随波，微微后退 / 前漂；按住时一直漂，松手后余波渐止 |

镜头会缓缓跟随，舟始终留在构图里。系统开启「减弱动态效果」时，晃动与落雪会相应减弱。

## 适配

- **构图**：舟的大小按宽高比连续取值（窄竖屏约占屏宽 45%，平板竖屏 39%，横屏 22%），再受屏高约束；竖屏时舟居中、略高于中线，横屏偏左。旋转或拖窗时平滑过渡，不跳。舟漂移时船尾、竿梢都不会出画。
- **视口**：画布高度用 `100dvh`（`100vh` 兜底）；标题、小印、提示、旧作入口、题诗都让开 `safe-area-inset-*`（刘海、Home 指示条）。禁止回弹、下拉刷新、双击缩放、长按菜单和选字。
- **触屏**：轻触＝一桨，左右轻扫＝随波，竖向拖动不算数；点「旧作 · 3D」不会触发划桨。触屏设备上提示自动换成「轻触 划一桨 · 左右轻扫 随波」，手机横屏再缩短。键盘照常。
- **字号**：标题、题诗、小印都用 `clamp()` 随屏缩放；竖屏手机上旧作入口挪到右上角竖排。
- **性能**：像素比最高 2（低端机 1.5），画布超过约 8MP 时再降；`resize` / `orientationchange` / `visualViewport` 合并防抖后才重画宣纸和舟；页面隐藏时暂停动画；雪片数随面积、上限 30。
- **旧作 3D**：补了安全区、触屏操作（轻触划桨、按住左右拖转向）和小屏 HUD 换行，其余未动。

已在 360×740、390×844、430×932、844×390、768×1024、820×1180、1180×820、1280×720、1440×900、1920×1080、2560×1080 下截图核对。

### 调试参数（截图 / 自动测试用，平时无影响）

- `#t=8`：开场先快进 8 秒；`#t=8&row=2`：快进末段划 2 桨；
- `#t=8&poem`：立刻显出题诗（不淡入），用来检查题诗与舟、UI 是否打架；
- `#debug`：把内部状态挂到 `window.__wubian`，供 Playwright 之类的脚本断言。

## 本地运行

```bash
python3 -m http.server 8765 --directory x1phyr.github.io
```

打开 http://localhost:8765/ 即可。无构建、无 CDN、无依赖。

## 文件

- `index.html` / `styles.css` / `main.js` —— 水墨版（当前首页）。宣纸与舟在离屏画布上只画一次，逐帧只画水纹、钓丝和雪。

笔法（湿笔洇边、笔毛飞白、水纹）改写自 huashu-art-motion 的 `91_hanjiang_min` 场景。
